# MineMap

Миникарта Minecraft на телефоне через QR-подключение.

## Статус

Планирование и разработка. Рабочей сборки пока нет.

## Целевая платформа

Minecraft Java Edition 26.3, Fabric, клиентский мод.

## Первая версия

- Назначаемая клавиша открывает меню с QR-кодом.
- Мод запускает локальный веб-сервер; телефон и компьютер находятся в одной Wi-Fi-сети.
- QR содержит ссылку со случайным ключом сессии. Ключ можно сбросить.
- Телефон показывает карту поверхности загруженных клиентом чанков, положение и направление игрока.
- Масштабирование и перемещение карты пальцами, следование за игроком.
- Обновления карты и позиции передаются без перезагрузки страницы.
- Миры и измерения разделяются; сервер останавливается при завершении клиента.

Неизвестные клиенту чанки недоступны. Серверный мод и облачный сервис для первой версии не требуются. Устанавливаемая PWA с HTTPS — следующий этап.

## Поддержка версий

Общее ядро отвечает за веб-сервер, сессии, протокол и мобильный интерфейс. Небольшой адаптер Minecraft отвечает за чанки, игрока, клавишу и меню. Для несовместимых версий выпускаются отдельные сборки. Совместимость заявляется после проверки; будущие версии автоматически не гарантируются.

## Инструменты

В объявлении Fabric для 26.3 рекомендованы Loom 1.17 и Gradle 9.6.0; Loader 0.19.5 указан как стабильный на дату объявления. Точные зависимости проверяются и закрепляются при настройке сборки.
