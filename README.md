# MineMap

Карта Minecraft на телефоне через QR. Первая версия для **Minecraft Java 26.3 + Fabric**.

## Статус

MVP `0.2.0-alpha.1` подготовлен к ручной проверке. GitHub Actions собирает клиентский мод, проверяет HTTP-сервер и телефонный интерфейс в Chromium и WebKit, включая подключение к серверу из готового JAR. CI также запускает загрузку клиента Minecraft до инициализации графики, проверяет Fabric, преобразование класса чанка, ресурсы HTTP и генерацию QR. Игровой мир и настоящий телефон требуют ручной проверки.

## Как использовать

1. Установи Minecraft Java 26.3 и Fabric Loader 0.19.5+. Fabric API 0.161.0+26.3 уже включён внутрь MineMap: отдельно скачивать его не нужно.
2. Положи единственный файл `minemap-0.2.0-alpha.1.jar` в папку `mods` нужного профиля на своём компьютере. Удали предыдущий JAR MineMap, если он уже установлен.
3. Подключи телефон и компьютер к одной сети. Хотспот ноутбука тоже подходит.
4. Зайди в мир и нажми **M**. Клавиша меняется в настройках управления. Если после обновления игра сохранила старую F8, назначь M в «Настройки → Управление → MineMap → Подключить телефон к карте».
5. Выбери IP ноутбука, доступный телефону. Для Windows-хотспота первым предлагается `192.168.137.1`, если такой адрес обнаружен.
6. Отсканируй QR камерой телефона. Если соединения нет, проверь выбранный IP и доступ Java через брандмауэр.
7. На телефоне двигай и масштабируй карту пальцами. «Игрок» возвращает слежение, ⛶ запрашивает полный экран, если браузер его поддерживает.

Меню не ставит одиночную игру на паузу. После закрытия меню карта продолжает работать. «Сбросить QR» отключает старую ссылку. Новый запуск игры создаёт новый ключ и порт.

## Совместимость с другими игроками

**Это исключительно клиентский мод.** Серверу и другим игрокам устанавливать MineMap не нужно. Ты можешь заходить на обычные серверы и принимать в свой LAN-мир игроков без MineMap. Обязательных Minecraft-пакетов, серверных entrypoint или изменений игрового мира мод не добавляет.

## Что умеет первая версия

- QR и выбор локального IPv4-адреса, включая хотспот.
- Локальный HTTP-сервер с ключом сессии и его сбросом.
- Поверхность над землёй и карта пещер на текущем Y под землёй; в Незере всегда используется срез.
- Ползунок Y на телефоне для ручного выбора среза и кнопка «Авто».
- Радиус чтения чанков берётся из дальности прорисовки Minecraft; неизвестные чанки не загружаются принудительно.
- Разведанные чанки сохраняются на компьютере между запусками, отдельно для мира, измерения и высоты.
- Цветные метки с названиями и X/Y/Z; сохранение меток на компьютере.
- Позиция и направление игрока, зум, панорамирование, слежение.
- Опрос позиции до 10 раз в секунду, сглаживание движения и поворота; передаются только изменённые изображения чанков.
- Автоматическое восстановление связи; очистка карты при выходе и смене мира/измерения.
- Данные мира читает только игровой поток; HTTP-потоки получают неизменяемые снимки.

Карта заполняется постепенно. Изменённые блоки помечают чанк для обновления; дополнительно чанки в зоне прорисовки проверяются по очереди. Игровой поток читает мир с ограничением работы за тик, сохранение выполняется отдельным потоком. При увеличении прорисовки заполнение дальних чанков занимает больше времени.

В пещерах стены темнее проходов, пол ищется не глубже 16 блоков ниже выбранного Y; глубокие шахты обозначаются отдельно. Авто переключается на срез, когда игрок ниже верхней поверхности более чем на два блока. Небольшие крыши/деревья могут влиять на автоматический выбор; ползунок позволяет выбрать нужную высоту. Цвета основаны на цветах блоков, без биомной окраски.

Сохранения карты находятся в `minemap/maps`, метки — в `minemap/markers` внутри папки профиля Minecraft. Метки ставятся в центре текущего вида карты кнопкой «Метки»: передвинь карту, введи название, выбери цвет и нажми «Сохранить». Координаты можно поправить перед сохранением, удалить метку — крестиком в списке. Для поверхности Y метки по умолчанию равен Y игрока, его можно изменить. Метки другого слоя отображаются полупрозрачно.

Одиночные миры различаются по пути сохранения, сетевые — по адресу сервера. Если сервер заменил свой мир по тому же адресу, старую карту потребуется удалить из `minemap/maps`.

Телефонный интерфейс работает локально без интернета и внешних CDN. Это пока обычный сайт. Устанавливаемая PWA потребует HTTPS и будет отдельным этапом. Полноэкранный режим зависит от браузера.

## Сборка

Нужен JDK 25 (`java -version` должен показывать 25). Gradle 9.6.0 скачает включённый Wrapper; при первой сборке нужен интернет для зависимостей:

```sh
./gradlew build
```

На Windows: `.\gradlew.bat build`.

Готовый мод: `build/libs/minemap-0.2.0-alpha.1.jar`. JAR с суффиксом `-sources` устанавливать не нужно. Альтернатива сборке: открой [GitHub Actions](https://github.com/Serafdim54/MineMap/actions/workflows/build.yml), выбери успешный запуск **для нужной ветки/коммита** и скачай артефакт `MineMap-26.3`; распакуй ZIP и возьми обычный JAR.

## Проверка MVP

Сборка запускает JUnit-проверки высот/пещер, сохранения чанков и меток, дельт/страниц карты, авторизации и HTTP-команд. Для браузерных проверок дополнительно нужны Node.js 22+ и JDK 25:

```sh
npm install --no-save --package-lock=false playwright@1.55.1
npx playwright install --with-deps chromium webkit
node tests/phone.cjs
MINEMAP_BROWSER=webkit node tests/phone.cjs
```

На PowerShell перед вторым запуском: `$env:MINEMAP_BROWSER="webkit"; node tests/phone.cjs`.

Проверяются настоящий сервер из собранного JAR, отрисовка, масштаб, перемещение, слежение, жест двумя пальцами в Chromium, смена мира с тем же измерением, обрыв/возврат сети, повторная загрузка повреждённого изображения, выход/вход в мир, сброс QR и отсутствие ключа. Скриншоты находятся в `build/phone-preview-*.png`.

Ручная проверка в игре:

1. Запусти профиль Fabric 26.3 и открой одиночный мир. Нажми M, сканируй QR и проверь, что карта заполняется в течение нескольких секунд.
2. Спустись в пещеру, выбери Y ползунком и вернись в «Авто». В Незере проверь срез под крышей. Пройди через границу чанка, повернись: координаты и стрелка должны обновляться. На телефоне проверь зум двумя пальцами, перемещение и кнопку «Игрок».
3. Перейди в другое измерение, затем выйди и открой другой мир: старая карта должна исчезнуть, а слежение включиться заново.
4. Отключи Wi-Fi телефона и включи снова: карта должна восстановиться автоматически. Сбрось QR: старая страница должна очистить карту и запросить новый код.
5. Создай цветную метку, отойди от разведанного места, затем перезапусти игру: метка и разведанные чанки должны сохраниться. Построй/сломай блоки в видимой области: соответствующий чанк должен обновиться.
6. Закрой Minecraft: телефон должен сообщить об обрыве связи. Подключение к следующему запуску выполняется по новому QR.

Если телефон не открывает ссылку, выбери в M адрес компьютера в общей сети (не `127.0.0.1` и не IP VPN), разреши Java входящие соединения в частной сети и проверь, что Wi-Fi не изолирует устройства. Порт случайный: ссылка из предыдущего запуска игры не подходит.

## Архитектура

- `dev.minemap.core`: локальный сервер, ключи сессии, снимки данных — без зависимостей от Minecraft.
- `dev.minemap`: адаптер Fabric 26.3, события клиента, выборка чанков, QR-экран.
- `resources/web`: мобильный Canvas-интерфейс без сборщика и сторонних скриптов.

Новые версии Minecraft подключаются отдельными адаптерами/сборками по необходимости. Совместимость заявляется после проверки; поддержка будущих версий автоматически не гарантируется.
